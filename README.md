# A2D 测试看板

集中查看机器人抓取测试结果：**测了什么模型、用了什么数据、测试多少次、成功率多少、主要失败原因是什么。**

页面支持筛选和点击查看详情。展示的是已发布的测试结果，不需要安装模型或仿真软件。

## 启动看板

需要仓库访问权限，以及 Git 和 Python 3（Linux / macOS）。

**第一次使用：复制整段命令到终端。**

```bash
git clone https://github.com/alex7537/a2d-eval.git
cd a2d-eval
bash start_dashboard.sh
```

**以后使用：在仓库目录运行这一条命令，自动拉取最新数据并启动。**

```bash
bash start_dashboard.sh
```

## 打开网址

| 在哪里启动 | 浏览器打开 |
|---|---|
| 自己电脑 | **http://localhost:8080** |
| 同事的服务器 | **http://服务器IP:8080**（向部署同事索取具体地址） |

默认端口 **8080**。关闭服务按 **Ctrl+C**。更新数据时先停止，再运行启动命令并刷新网页。

端口被占用时可换成 8081：`PORT=8081 bash start_dashboard.sh`。

## 如何看结果

- **成功率＝成功次数 ÷ 有效测试次数**；系统异常造成的无效测试单独列出。
- 不同场景、测试方法的结果要分开比较。
- 页面顶部显示结果更新时间；尚未发布的测试不会出现在这里。

服务器需允许访问所用端口。本服务没有登录验证，请部署在同事可访问的内部网络。
