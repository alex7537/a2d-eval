# A2D 训练与测试看板

集中查看机器人策略的训练和抓取结果：**W&B训练了什么、最终部署哪个checkpoint、对应场景成功率多少、主要失败原因是什么。**

页面分为两个独立入口并支持筛选和点击查看详情：根页面查看训练模型，
`/evaluation.html`查看测评记录。展示的是已发布快照，不需要安装模型或仿真软件。

## 启动看板

需要仓库访问权限，以及 Git 和 Python 3（Linux / macOS）。

**第一次使用：复制整段命令到终端。**

```bash
git clone https://github.com/alex7537/a2d-eval.git
cd a2d-eval
bash start_dashboard.sh
```

**以后使用：在仓库目录运行这一条命令，自动拉取最新数据并启动。**

```bash
bash start_dashboard.sh
```

## 打开网址

| 在哪里启动 | 浏览器打开 |
|---|---|
| 自己电脑 | **http://localhost:8080** |
| 同事的服务器 | **http://服务器IP:8080**（向部署同事索取具体地址） |

顶部“训练模型／测评记录”可在两个页面间切换；也可直接打开
`http://localhost:8080/evaluation.html`。

默认端口 **8080**。关闭服务按 **Ctrl+C**。更新数据时先停止，再运行启动命令并刷新网页。

端口被占用时可换成 8081：`PORT=8081 bash start_dashboard.sh`。

## 如何看结果

- **训练表**每天北京时间 09:17 自动检查 W&B（可能延迟）；仅新增任务、任务状态变化或任务移除时更新并提交，进度/指标单独变化不提交。点击可打开原始 W&B run。
- 每日检查可能跳过一天内的中间状态；看板保留最近一次有状态变化时的快照，不是实时进度。支持 Actions 手动检查。
- **训练和测评只通过明确的run ID、checkpoint role和bundle SHA关联**；没有证据的模型显示“尚未测评/待关联”。
- **成功率＝成功次数 ÷ 有效测试次数**；系统异常造成的无效测试单独列出。
- 训练loss和val MSE不是机器人成功率，不能互相替代。
- 不同场景、测试方法的结果要分开比较。
- 页面顶部显示结果更新时间；尚未发布的测试不会出现在这里。

服务器需允许访问所用端口。本服务没有登录验证，请部署在同事可访问的内部网络。
